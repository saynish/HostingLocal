# 🖥 Nodecraft - локальная панель серверов

Личная панель на Windows: создать Minecraft-сервер или Telegram-бота, загрузить его файлы, запустить процесс, посмотреть вывод и отправить команду. Слушает **только 127.0.0.1**. Не является публичным хостингом и не открывает сайт в интернет.

## Запуск

1. Установите [Node.js 24 или новее](https://nodejs.org/). Дважды нажмите `start.cmd` или выполните `start.cmd` в cmd.
2. Откройте **точный адрес**, напечатанный в окне cmd: `http://127.0.0.1:ПОРТ`. Порт свободный и выбирается при запуске. Не закрывайте окно cmd, пока серверы нужны.
3. При первом открытии придумайте пароль длиной не менее 10 символов. Затем войдите и создайте сервер.

## 🧱 Minecraft

Нужна отдельно установленная Java (JDK; команда `java -version` должна работать в cmd). На этом ПК Java сейчас **не установлена**. Выберите Java-версию под ваш серверный `.jar`, скачайте файл сервера из доверенного источника и загрузите в панель под именем `server.jar` (либо укажите фактическое имя в настройках). Ознакомьтесь с [Minecraft EULA](https://www.minecraft.net/en-us/eula), поставьте галочку согласия и нажмите «Запустить». Панель перед запуском создаёт `eula.txt`, передаёт Java лимит памяти и `nogui`. Игроки с этого ПК могут подключиться к `localhost:25565`; сетевой доступ Minecraft зависит от настроек `server.properties` и брандмауэра, сама веб-панель по сети недоступна. Если Java отсутствует, ошибка будет в консоли панели.

## 🤖 Telegram-бот

Загрузите готовый файл `index.js` (Node.js) или `bot.py` (Python), укажите его как файл запуска и нажмите «Запустить». `py` и Node.js уже есть на этом ПК. Для бота обычно нужны токен от BotFather и зависимости: настройте исходный код и установите его зависимости **в каталоге конкретного сервера** (`data/servers/ID`) до запуска. Не кладите токены в общедоступные исходники; загруженные файлы локальны, но владелец этого ПК может их прочитать. Панель не создаёт Telegram-бота и не получает токен вместо вас. Используйте только доверенный код: загруженные файлы запускаются с правами текущего пользователя Windows.

## 🔒 Данные и безопасность

Настройки и хэш пароля: `data/panel.sqlite`. Файлы: `data/servers/ID`. Эти каталоги сохраняются между перезапусками панели; запущенные процессы при закрытии панели останавливаются, после повторного открытия их нужно запустить снова. Удаление сервера **безвозвратно удаляет** его каталог, сделайте резервную копию заранее. Загрузка одного файла — до 100 МБ. Доступ к панели ограничен localhost, сессии хранятся в памяти до 12 часов, изменение пароля завершает все сессии. Это инструмент для одного доверенного пользователя компьютера, не выставляйте порт панели в интернет.
